# Attrax - Mentorly

AI-powered creator mentor platform — an intelligent system that helps content creators grow through data-driven insights, personalized recommendations, and automated publishing workflows.

## Project Structure

| Module | Description |
|--------|-------------|
| `ClawCore` | Core agent framework for creator assistance |
| `RecSys` | Recommendation system for content and trends |
| `SmartAIMentor` | Main application — frontend + backend + AI mentor |
| `platform_data_fetcher` | Social media data collection tools |
| `popularpays-mcp-demo` | Brand collaboration MCP integration demo |
| `user-post-skills-set` | Creator content analysis skill set |
| `mentoraix` | Project configuration and utilities |
